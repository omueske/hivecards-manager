# Daily Work with Hives

This page provides a simple routine for everyday field work.

## Recommended workflow

1. **Select hive**
2. **Record inspection**
3. **Note anything unusual**
4. **Document actions taken**
5. **Plan the next check**

---

## 1) Before inspection

- note weather and time quickly
- prepare required material
- define inspection goal clearly

Example goals:

- check feed level
- evaluate brood pattern
- verify queen-right status
- assess varroa situation

---

## 2) Enter data in hive log

Use only relevant fields.

### Minimal useful data

- date
- entry type
- short note

### Add when useful

- brood status
- varroa value
- weather
- frame count
- actions taken

---

## 3) Treatments and feeding

Whenever you treat or feed, always record:

- product
- amount
- date
- effect/observation note

This keeps colony development traceable.

---

## 4) Data quality tips

- keep wording short and clear
- use consistent terminology
- write entries right after field work
- prefer regular short notes over rare long notes

---

## 5) Good note style example

Poor:

- “all normal”

Better:

- “brood on 5 frames, queen seen, feed sufficient, no swarm cells”

Best:

- “closed brood pattern on 5 frames, queen seen, fed 1l syrup, next check in 7 days”

---

## 6) When you are unsure

If a colony looks uncertain:

1. write a more detailed note now
2. schedule a near-term follow-up
3. make observation date explicit

This supports decisions based on evidence, not memory.
