# Getting Started (for beginners)

## What you can complete in the first 30 minutes

This guide is written for beekeepers without an IT background.

### Goal

By the end, you will have:

- created your account
- added at least one apiary
- added at least one hive
- created your first hive log entry

---

## 1) Create an account and sign in

1. Open the app and go to **Register**.
2. Enter name, email, and password.
3. Sign in with your credentials.

Tip: Use a strong password and store it safely.

---

## 2) Check language and profile

1. Select your language in the top-right selector.
2. Open **Profile** from the menu.
3. Optionally set breeder defaults (L1A/LV1A/Z1A).

Why useful? These defaults save time later in the Breeding Book.

---

## 3) Add an apiary

1. Open **Apiaries**.
2. Click **New location**.
3. Enter location details and save.

If you manage multiple places, add all of them now.

---

## 4) Add a hive

1. Open **Hives**.
2. Click **Create Hive**.
3. Select an apiary and save core data.

Your first hive is now available.

---

## 5) Add first hive log entry

1. Open the hive.
2. Create a new chronology entry.
3. Select type (for example inspection).
4. Save date, notes, and key observations.

You now have a clean starting record.

---

## 6) Common beginner questions

### Do I need to fill everything now?

No. Start with required fields and improve data quality over time.

### Can I edit data later?

Yes. Most records can be updated later.

### I do not see data after login

Reload once or sign out and sign in again.
