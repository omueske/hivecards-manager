# Help & FAQ (non-technical users)

## Login and access

### I cannot sign in

- verify email/password
- check upper/lower case
- use password reset

### I get logged out again

- reload the browser page
- sign out and sign in again
- clear browser cache if needed

---

## Data entry

### I entered wrong data

No problem: open record, edit, save.

### Why can I not edit a field?

Some fields are intentionally auto-generated (for example 1A).

### Date formats look inconsistent

Use date pickers and keep your profile date mode consistent.

---

## Breeding Book and CSV

### Import fails

Common reasons:

- missing required columns
- unsupported date format
- inconsistent values

Use import preview to catch issues first.

### Export does not download

- check browser download blocker
- try another browser
- sign out/in and retry

---

## Queens and assignments

### Queen appears in wrong hive

Check queen assignment history:

- open assignment
- date of last move

History is updated automatically during reassignment.

---

## General tips

- always save changes
- keep notes short but regular
- when unsure, add a note instead of leaving fields empty

---

## If nothing works

1. reload page
2. sign out/sign in
3. retry with a small test change
4. capture error text for support
