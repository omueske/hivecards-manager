# Managing Queens (simple guide)

Queen management helps you track origin, status, and reassignments clearly.

## 1) Key fields

- **Label**: free name (for example Q2025-A)
- **Queen year**: year class
- **Marking color**: auto-suggested
- **Origin**: source/country
- **Mating type**: for example natural mating, mating station, island mating
- **Status**: active, spare, dead, sold

---

## 2) Use status consistently

- **active**: currently assigned to a hive
- **spare**: available, not currently assigned
- **dead/sold**: no longer in active use

Consistent status values improve reporting quality.

---

## 3) Assign queen to hive

When assigning, history is managed automatically.

This means:

- previous active assignment is closed
- new assignment starts with date

You can later see exactly where and when each queen was used.

---

## 4) Avoid common beginner mistakes

- creating queens without clear labels
- not updating status
- moving queens without date context
- leaving origin empty

Recommendation: use one consistent naming pattern.

---

## 5) Practical tip

If you keep spare queens, mark them as **spare** immediately and add a short note about origin/source.
