# Roadmap (High-level)

## Phase 0 — Discovery (2–4 Wochen)
- Nutzerrecherche
- Validierung der Kernannahmen
- Technische Machbarkeitsprüfung

## Phase 1 — MVP (4–8 Wochen)
- Implementiere Kern-Features
- Basis-Auth, Persistenz, UI
- Erste Testnutzer:innen onboarden

## Phase 2 — Beta (4–6 Wochen)
- Feedback-Schleifen
- Fehlerbehebung, Optimierungen
- Ausbau wichtiger Features

## Phase 3 — Launch
- Marketing / Kommunikation
- Betriebssicherstellung

## Meilensteine
- M1: Abschluss Discovery
- M2: MVP-Release
- M3: Beta-Feedback abgeschlossen
- M4: Launch
